# Gothic reference library

16 supplied JPEG originals (REF-001–REF-016), copied byte-for-byte and renamed descriptively, plus four Gothic foliate ornament references (REF-017–REF-020) under `gothic-foliate-ornament/`. No recompression, cropping, substitutes or duplicate placements are included.

## Numbering and navigation
REF-001 through REF-016 follow the image order in the latest user message. The earlier conversation order is unknown and is not reconstructed. In this numbering the English window typology is REF-001 and the bracket/corbel catalog is REF-003.

Each image has one primary home. `reference-index.json` records its original filename, current-message number, category, design role, uncertainty, byte size and SHA-256 checksum. Historical/style labels are provisional visual classifications unless explicitly described as text visible on the image.

All requested folders are present, including empty ones. Empty folders mark collection opportunities, not missing ZIP entries. Related content can be found through the cross-references below without duplicating images.

## Extract on macOS
Download gothic-reference-library.zip to Downloads. In Terminal:

```sh
mkdir -p /Users/retochen/Documents/GitHub/yc2925/
unzip -n ~/Downloads/gothic-reference-library.zip -d /Users/retochen/Documents/GitHub/yc2925/
```

This creates `yc2925/references/`. The `-n` option preserves any existing same-name files. Alternatively double-click the ZIP in Finder, then move its `references` folder into the repository; review any existing-folder merge before accepting it.
